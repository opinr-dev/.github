# Opinr

**An opinionated framework for running teams of AI agents.**

Opinr is an open-source framework for running a team of AI agents. Claude Code, Codex and opencode run unchanged, each live in its own terminal on [Herdr](https://herdr.dev). Opinr makes the set-up decisions for you:

- **A chief of staff in every workspace**, one for each business, side project or part of your life, that you talk to from Slack or Telegram.
- **The knowledge loop**: every session ends with a note, filed into the workspace's knowledge base for you.
- **Scoped skills**: each workspace picks and pins its own skills from a library, and each agent picks from that.
- **Guardrails outside the agent**: rules enforced by GitHub, git hooks and a broker, not by asking the agent nicely.

**Status, November 2026:** not released yet. Milestone 1 of 9, chatting with a chief of staff from Slack, is built and in daily use. The code goes public here, under Apache 2.0, when it's ready for others.
